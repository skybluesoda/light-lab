# 실행과 사용

루트 README의 빠른 시작으로 프론트엔드를 빌드한 뒤 `./start_app.sh`를 실행합니다. Blender 경로는 `BLENDER_BIN`으로 지정합니다. 저장소는 Blender 자체를 포함하지 않습니다.

1. 광원 5개의 색·세기·켜기 상태와 해상도·샘플·엔진을 선택합니다.
2. 렌더를 실행합니다. 완료한 엔진부터 결과가 표시됩니다. 변경한 입력은 다음 작업에 적용됩니다.
3. 두 결과가 있으면 겹쳐 비교합니다. 이미지를 클릭해 확대·전체 화면으로 관찰합니다.
4. 결과 ZIP은 이미지·설정·보고서·측정 CSV를 포함합니다. 설정 JSON은 다른 실행에 가져올 수 있습니다.

같은 조건의 정상 결과가 있으면 캐시를 재사용합니다. 새 시간 측정에는 ‘저장 결과 대신 새로 측정’을 선택하세요. 반복 측정은 준비 1회와 본측정 3회를 새로 렌더하며, 실제 GPU에서는 아직 반복 통계를 검증하지 않았습니다.

확대 창: 휠·+/−로 확대, 드래그·방향키로 이동, 0 맞춤, 1 원본 배율, F 전체 화면, Esc 닫기. 100%는 CSS 픽셀 기준입니다. 낮은 해상도를 확대해도 세부 정보가 새로 생기지는 않습니다.

## 문제 해결

- 화면 빌드 없음: `cd app/frontend && npm install && npm run build`.
- Blender 없음: 설치 위치를 `BLENDER_BIN`으로 지정. PATH의 `blender`도 탐색합니다.
- Metal 접근 불가: 일반 macOS 터미널에서 실행. 앱은 렌더 전에 접근을 점검하고 실패 시 Blender를 반복 시작하지 않습니다.
- 포트 충돌: `LIGHT_LAB_PORT=8766 ./start_app.sh`.
- 원본 렌더 실패: `app/data/jobs/<id>/render.log`와 `render_report.json` 확인. 실패·취소 결과는 두 엔진 완료 캐시가 아닙니다.

새 저장소에는 개인 렌더 기록이 없습니다. 대표 Eevee 이미지는 기본 미리보기로 제공하며 개인 작업 이력에 자동 등록하지 않습니다. 현재 렌더는 macOS Metal을 검증 기준으로 삼고, CPU 실행은 개별 스크립트 실험 범위입니다.
