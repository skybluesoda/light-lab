# 라이트맵 없는 간접광 근사 실험

현재 결과는 사용자 확인을 완료했습니다. 실제 Eevee 렌더 2.566초, 라이트맵 베이크 0초, Raytracing/Fast GI OFF를 JSON과 이미지에서 확인했습니다. 다음 독립 조명 제어 구현의 기준으로 선택했습니다. 이 모드의 같은 설정 Cycles 비교는 아직 실행하지 않았습니다.


기존 제작용 `scene.py`, 프리셋 캐시와 이전 이미지는 유지합니다. 별도의 `scene_approx.py`로 하나의 Eevee 이미지를 만듭니다.

```bash
./preview_approx.sh
```

일반 macOS 터미널에서 실행하세요. 결과는 `preview-approx/eevee.png`, `light_lab.blend`, `render_report.json`, `render.log`에 저장됩니다. 기본 480×360, Eevee 128 samples입니다. 960×540으로 보고 싶으면 다음처럼 실행합니다:

```bash
./preview_approx.sh --resolution 960 540
```

5개 조명은 `config/approx-preview.json`에서 독립적으로 설정합니다. 예시는 패널 옅은 흰색, 왼쪽 상단 푸른색, 오른쪽 상단 따뜻한 주황색, 좌우 모서리는 각각 별도의 색상입니다. `color_srgb`는 #RRGGBB이며 내부에서 선형 RGB로 바꿉니다. 패널은 strength, 나머지는 power_w로 세기를 설정합니다. 모서리 발광 스트립의 세기도 해당 광원 전력과 함께 바뀝니다.

라이트맵·볼륨 프로브 베이크·Cycles 렌더·노이즈 제거 사전 처리는 실행하지 않습니다. Eevee Raytracing/Fast GI는 OFF입니다. 코브와 모서리의 직접광은 실제 Area Light로 계산하고, 패널은 Eevee용 Area Light 프록시로 보완합니다. 이 프록시는 Cycles로 비교할 때 숨깁니다.

간접광은 공간의 위치에 따라 변화하는 소스별 부드러운 색상 필드를 셰이더에서 합산합니다. 거리와 광원 세기에 반응하는 예술적 근사이며 에너지 보존, 차폐, 실제 다중 반사, 그림자 안쪽의 정확성을 계산하지 않습니다. 조형물이나 벽을 새로 추가해도 이 필드는 가려지지 않습니다. 고정된 흰색 환경광은 넣지 않았고, 모든 조명을 끄면 근사 환경광도 0이 됩니다. 벽·바닥·천장의 Eevee 출력에만 적용하며 Cycles의 물리 재질 출력은 유지합니다.

광택은 기존 Sphere 반사 프로브의 래스터 캡처를 사용합니다. 정확한 거울 반사가 아니며 프로브 캡처 준비 시간도 최종 렌더 시간에 포함됩니다. 밝기 보정이 필요하면 `--ambient-gain 0.7`처럼 전체 근사 강도만 조절할 수 있습니다.

현재 검증: 5개 독립 설정, 꺼진 광원의 기여 0, 좌우 색상 분포, 선형 세기 변화, 입력 검증과 기존 캐시 검사를 포함해 테스트 23개 통과. 현재 채팅 세션에서 Metal 장치를 찾지 못해 Blender를 실행하지 않았고 실제 이미지는 아직 생성하지 않았습니다. 실행 전 장치 검사를 통과하지 못하면 Blender를 시작하지 않아 반복 충돌을 피합니다.
