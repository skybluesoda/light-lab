# 자료 출처와 배포 범위

`images/eevee.png`와 `images/cycles.png`는 이 프로젝트의 절차적 장면에서 생성한 대표 결과입니다. `render_report.json`은 같은 작업의 엔진 보고서입니다. 외부 텍스처·모델은 사용하지 않습니다.

발표 PPT/PDF에는 PBRT, NVIDIA GPU Gems, Pixar RenderMan의 외부 그림이 포함되어 있습니다. 해당 자료는 이용 조건을 별도로 확인해야 하므로 **이 저장소에 포함하지 않았습니다**. 기술 문서는 원문을 링크하고 자체 설명을 사용합니다.

Blender, Python, React, FastAPI 및 의존성은 저장소에 번들하지 않습니다. 각각의 라이선스·설치 조건을 따릅니다. 원저작자의 선택 없이 이 프로젝트에 MIT 등 오픈소스 라이선스를 임의로 부여하지 않았습니다. 비공개 협업용 저장소이며 공개·재배포 전 코드 라이선스를 결정해야 합니다.
